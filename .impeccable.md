## Design Context

### Users

Developers controlling Claude Code or Codex from Telegram, often from a phone and away from their terminal. They need to choose a local repository, send a task in plain language, follow progress, and decide what to do with the result.

### Brand Personality

Calm, direct, and capable. The bot should feel like the message-based counterpart of Codex or Claude Code: technical without exposing implementation jargon, concise without becoming cryptic.

### Aesthetic Direction

Native Telegram conversation patterns, compact status messages, and specific action labels. Prefer progressive disclosure through inline buttons over command-heavy help text.

### Design Principles

- Get users from `/start` to their first real task in two clear choices.
- Keep ordinary work conversational; reserve commands for navigation and power use.
- Always make the active repository and agent visible before work begins.
- Pair every error or empty state with the next useful action.
- Edit progress in place to keep the chat readable.
